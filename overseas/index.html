Where analysis sits

数据分析是第 5 环，不是全部

投放是六个环节串起来的活。看数只是其中一环——它负责判生死，不负责代替前面四环的准备工作。

1 / 6
01 / BRIEF

目标翻译成约束

把 GMV 目标反推成 CPM 上限、CPA 红线、内容条数。算不清就别开投。

02 / STRUCTURE

钱怎么分

测试 / 放量 / 防守三层预算，一个维度一个层级，每条计划带止损。

03 / CREATIVE

投给谁、说什么

人群 × 场景 × 前 3 秒钩子，做成矩阵；一次只跑一列。

04 / TEST

先给足样本

固定窗口、最小样本达标才下结论，窗口内不改结构。

05 / REVIEW

回看与判定

三层基准、四个指标、分布先于个体。只回答：继续、改、还是停。

分析在这里
06 / ACTION

预算重排

按四象限放量 / 换素材 / 换人 / 关停，梯度放量并留测试位。

多数投放复盘的通病是从第 5 环开始写——直接甩一堆图表，却不交代红线怎么定、预算怎么分、素材为什么这么拍。这份作品和这套 SOP 都把顺序倒过来：先有判断框架，数据才有地方落。
Capability

按投放链路拆的能力，不是按工具拆

不说「精通 Excel / SQL / BI」，说清每个环节我能交付什么。

06 blocks
01 · BRIEF能算

预算与目标拆解

用单均毛利反推 CPA 上限、用 ROI 红线反推 CPM 上限，把「要增长」落成可执行的数字区间和止损条件。

  • CPA 上限
  • CPM 天花板
  • 预算盘
  • 止损线
02 · STRUCTURE能搭

账户与预算结构

按赛道或达人层级切分计划，命名可追溯，单变量测试，保证每一块钱都能说清花在哪、带回什么。

  • 分层预算
  • 计划命名
  • 单变量
  • 归因可插拔
03 · CREATIVE能定

人群与内容策略

人群分核心 / 扩展 / 泛兴趣，内容按场景和前 3 秒钩子建矩阵；用「情绪价值 > 参数说明」这类可复用的内容语法。

  • 人群分层
  • 钩子矩阵
  • 脚本 Brief
  • UGC 引导
04 · CHANNEL能谈

达人 / 联盟渠道

达人分层与双阈值筛选，CPS / 寄样 / 置换的结算方式与真实成本拆账；知道佣金、退货、履约分别吃掉多少毛利。

  • KOL 分层
  • 双阈值
  • CPS 佣金
  • 寄样置换
05 · REVIEW其中一环

效果回看与判定

三层基准换着看，先看分布再看个体；分得清过程指标与结果口径，不用「到店人数」给项目下结论。

  • 三层基准
  • ROI / CPA
  • 口径对齐
  • 异常剔除
06 · DELIVERY能写

复盘与协作交付

一页 Brief、周报模板、复盘文档；结论先行，每条洞察必须能翻译成一个动作，否则不写进报告。

  • 一页 Brief
  • 周报
  • 复盘文档
  • 动作清单
Judgement rules

三条我不会让步的判定规则

RULE 01

先算红线，再谈规模

ROI 1.13 在报表上是「达成」，在生意上只是刚过盈亏线。没算清单均毛利和 CPA 上限，规模越大风险越大。

这次的红线：ROI ≥ 1.0，实际 1.13 —— 安全垫只有 13%。
RULE 02

贵不等于亏，便宜不等于赚

CPM 只说明曝光买得贵不贵，赚不赚钱看 ROI。反过来，CPM 最低的达人也可能因为量太小而没有商业价值。

所以要两个阈值一起用：曝光效率一组，规模 × 质量一组。
RULE 03

过程指标不能当结论

到店人数、间接转化这类指标会重复计数、无法去重，只能做品牌间相对对标；项目值不值得投，一律看成交 GMV 与 ROI。

同一用户 21 天内多次下单，会被重复计入转化人数。
Boundary

这份作品集的边界

能背书什么、不能背书什么，先讲清楚，省掉面试时的误会。

  • 01
    数据真实，已脱敏。案例数据取自实际投放后台与分析表，品牌、竞品、达人全部代号化；金额与比率未做美化，保留原始的「不完美」——包括 18% 无法归类的效果。
  • 02
    只有一份作品，因为只有一个项目能完整复盘。不拿仿真数据凑数量。其他项目（电商经营与库存分析）留在原版作品集，定位不同，不混进这条投放主线。
  • 03
    SOP 是方法沉淀，不是客户方案。阈值区间来自本项目实测与公开基准区间，换品类需要重新标定；SOP 内不含任何客户数据。
  • 04
    经历不在这页展开。公司、时间线、职责范围以简历 PDF 为准，避免作品集和简历出现两套说法。

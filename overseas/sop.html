SOP v1.0 PAID MEDIA OPTIMIZATION · 6 STAGES / 24 CHECKS

投放逻辑优化 SOP：
把「看情况」变成「按条件」

这套流程解决一个具体问题：投放复盘经常停在「效果不错 / 不太行」，说不清下一步改什么。每一阶段都必须有输入、动作、判定条件和产出物，缺一项就不算走完。适用于抖音 / Meta / Google / TikTok 的信息流与达人投放，换平台不用重写结构。

PRINCIPLES

四条原则，决定这套 SOP 长什么样

流程本身不难抄，难的是这四条约束——它们决定了每一步怎么做判断，也是这份 SOP 跟「投放 checklist」的区别。

01

单变量

一次只动一个维度：人群、内容、出价。同时改三处，赢了不知道为什么赢，输了也不知道该回退哪个。

02

先样本，后结论

没到最小样本量不下判断。第 2 天的 CTR 下跌大概率是学习期噪声，不是内容不行。

03

基准跟着层级换

大盘看竞品，账户看自身均值，单元看同层级内均值。同一份数据换三个基准，结论可能完全不同。

04

结论必须能变动作

每条结论都要能翻译成「加预算 / 换素材 / 换人 / 关停」之一，否则只是描述，不写进复盘。

WHY THIS ORDER顺序不能换：没有红线的优化是瞎调，没有结构的测试是浪费，没有样本的判定是猜。下面六阶段按实际执行顺序排，每个阶段都给了「什么时候可以进下一阶段」的退出条件。
S1

Brief 拆解：把目标翻译成约束

这一步的产物是一页纸，不是一份 PPT。核心是三个数：CPA 上限、CPM 天花板、最小样本。算不出来就别开投。

S1

Brief 拆解

用毛利和红线反推可承受的成本区间

投前 · 半天
INPUT
  • GMV / 订单目标与周期
  • 现金预算与是否可追加
  • 客单价、毛利率、退货率
  • 历史 CPM / CVR / 转化成本
ACTION
  • 用单均毛利定 CPA 上限：CPA ≤ AOV × 毛利率 ×（1 − 退货率）
  • 用 ROI 红线反推 CPM 天花板：CPM ≤ CVR × AOV × 1000 ÷ ROI 红线
  • 按历史有效观看中位数，反推需要的曝光量与内容条数
  • 标注不可动约束：档期、平台政策、品牌词库存
OUTPUT
  • 一页 Brief（目标 / 红线 / 预算盘）
  • CPA 与 CPM 两个上限值
  • 止损条件与复盘节奏
检查项（4 项全过才进 S2）
CPA 上限低于单均毛利
ROI 红线有明确出处（财务或业务口径）
测试预算单列，且不超过总预算 25%
写清「什么情况下停止投放」
常见错误

只写「ROI 要做到 3」，不写「在什么客单、什么毛利、什么退货率下」。目标一旦脱离约束，执行层只能靠压价和堆量硬凑。

S2

结构搭建：让每块钱都有任务

结构的目的是可归因：关掉任何一条计划，都能说清它花了多少、带回多少。做不到这一点，后面的优化全部失效。

S2

账户与预算结构

分层预算 + 单变量切分 + 命名规范

投前 · 1 天
INPUT
  • S1 的预算盘与红线
  • 可投的渠道 / 达人层级 / 赛道清单
  • 素材产能（能出多少条 / 周）
ACTION
  • 预算切三层：测试 15–20%、放量 50–60%、防守 20–25%
  • 一个维度一个层级（按赛道或按达人层级），不交叉混投
  • 命名统一：平台_目标_人群_内容类型_日期
  • 每条计划独立止损：花费上限 / CPA 上限 / 观察天数
OUTPUT
  • 预算分配表
  • 计划清单与命名规范
  • 止损规则表
检查项
任取一条计划，能还原「花多少、带多少」
没有两条计划同素材同人群互相抢量
每条计划都有止损线，不是只有总预算
测试位独立，不被放量计划挤占
常见错误

把「所有达人」塞进一条计划。跑出来的均值既不能用于加预算，也不能用于砍人——结构一开始就废了。

S3

人群 × 内容矩阵：投给谁、说什么

把「投给谁」和「说什么」拆成格子，一次只跑一列。矩阵的价值不是全跑一遍，而是知道每一格在验证什么假设。

S3

人群与内容矩阵

3 人群 × 3 钩子，先定列再定行

投前 · 2–3 天
INPUT
  • 品类购买频次与决策路径
  • 历史跑赢 / 跑输的内容样本
  • 达人池与报价区间
ACTION
  • 人群分三层：核心（品类现客）/ 扩展（相邻场景）/ 泛兴趣
  • 场景取 3 个高频真实场景 + 1 个反差场景
  • 前 3 秒钩子分三类：痛点直给 / 反差叙事 / 情绪审美
  • 筛人用双阈值：曝光效率一组，规模 × 质量一组
OUTPUT
  • 素材矩阵表（人群 × 钩子）
  • 脚本 Brief（含前 3 秒逐字稿）
  • 达人分级名单
检查项
每条素材能回答「给谁看、解决什么、为什么现在看」
钩子不重复：三条素材不是同一句话换开头
筛人至少两个阈值，不用单一排名
矩阵有留白，不是一条素材讲完所有卖点
常见错误

一条素材塞满卖点。看起来「信息量大」，实际是不知道对谁说话——点击率会被平均掉，测不出哪句话有效。

S4

冷启测试：先给足样本，再判生死

这一阶段唯一的任务是拿到可信的判定依据，不是拿量。窗口内不改结构、不提前砍、不提前加。

S4

冷启与最小样本

固定窗口 + 固定变量 + 达标才判

投中 · 3–7 天
INPUT
  • S3 的矩阵与达人名单
  • S1 定下的最小样本标准
  • 平台学习期规则（避免误判）
ACTION
  • 给每组设定最小样本：有效观看 / 点击 / 转化任一达标才判
  • 固定测试窗口，窗口内不动结构与出价
  • 记录异常：素材审核失败、达人改期、平台限流，单独标注
  • 窗口结束当天出「保留 / 观察 / 淘汰」三档名单
OUTPUT
  • 测试排期表
  • 样本达标情况表
  • 三档名单（保留 / 观察 / 淘汰）
检查项
没有在样本不足时关停或加预算
每组只有一个变量在变
异常项已单独标注，没混进结论
「观察」档有明确的二次判定时间
常见错误

第 2 天 CTR 掉就砍。学习期波动通常在前 48 小时最大，这时候关停，砍掉的是本来能跑出来的素材。

S5

数据回看：分析只占这一环

它的职责很窄：判断继续、修改还是停止。不负责解释人群为什么买、也不负责编内容策略——那是前面几环的事，这里只做判定。

S5

效果回看与判定

三层基准 + 四个指标 + 分布先于个体

投中 · 每周
INPUT
  • 平台后台数据 + 后端成交数据
  • 竞品 / 行业基准区间
  • S1 的红线与 S4 的样本表
ACTION
  • 三层基准：大盘（竞品）→ 账户（自身均值）→ 单元（同层级内均值）
  • 只看四个指标：成本、效率、转化、结果
  • 先看分布（多少比例单元高于均值），再看个体
  • 平台数与后端数对账，差额超过 5% 先查口径再下结论
OUTPUT
  • 效果诊断表（四类判定）
  • 口径差异说明
  • 下一轮动作建议
检查项
所有比率共用同一个分母
归因窗口一致，没有拿 7 天数比 21 天数
过程指标没有被当成项目结论
异常值单独剔除并说明原因
常见错误

用「到店人数 / 间接转化」评估项目值不值。这类指标会重复计数、无法去重，只能做品牌间相对对标，项目结论必须回到成交 GMV 与 ROI。

S5 最容易越界的地方看数的人很容易顺手写策略：「因为音乐类转化低，所以品牌要年轻化」。这是从数据直接跳到品牌判断，缺了 S3 的内容假设与达人访谈。S5 只能输出「哪一类该加、哪一类该砍」，不能输出「品牌该是什么样」。
S6

预算重排：四象限定动作

把 S5 的判定翻译成预算动作。每个单元只能落进一个象限，落不进去说明数据还不够，回 S4 补样本。

高转化 · 低成本SCALE

加预算，梯度上浮 20–30%，观察 2–3 天成本弹性；弹性可接受就继续，抬过头回退一档。

高转化 · 高成本REBUILD

不砍人，改内容：换钩子、换场景、换前 3 秒。成本高但转化在，说明人群对了、表达贵了。

低转化 · 低成本REPLACE

换人群或换承接。便宜说明曝光买得对，转化低大概率是落地页或人群意图不匹配。

低转化 · 高成本STOP

直接关停，不做「再优化一版」的抢救。省下来的钱进测试位，比抢救更划算。

S6

重排与放量

梯度放量 + 留测试位 + 沉淀语法

投后 · 每轮
INPUT
  • S5 的四类判定结果
  • 下一周期预算与目标
  • 素材库存与达人行期
ACTION
  • 按四象限分配：放量 50–60%、修改 20%、替换 10%、关停释放
  • 放量梯度单次 20–30%，不翻倍
  • 始终留 10–15% 做新测试，防素材衰减
  • 把胜出内容写成「语法卡」：钩子 + 场景 + 情绪 + 产品露出方式
OUTPUT
  • 下一轮预算表
  • 测试清单与黑名单
  • 素材语法卡
检查项
放量后 CPA 仍在红线内
有备份素材，不押单一内容
关停释放的预算有明确去向
阈值和语法已写进下一轮 Brief
常见错误

一次把预算翻倍。成本抬升滞后 2–3 天才显现，等看到的时候已经多花了整周预算。梯度放量是唯一安全的做法。

TOOLS

三个可直接拿去用的东西

阈值表用来判断，Brief 模板用来对齐，复盘模板用来交付。

指标回答什么阈值怎么定误判风险
CPM曝光买得贵不贵品类均值 ±20% 为正常区间低 CPM 可能买到低质曝光
有效观看率内容留得住人吗自身历史中位数，不用行业均值平台口径不一，需统一分母
CTR钩子有没有吸引力同素材类型内比较，不跨类型样本不足时波动极大
CVR承接能力分层看：人群 / 落地页 / 时段混入品牌词会虚高
CPA单元效率≤ 单均毛利 ×（1 − 退货率）忽略退货与履约成本
ROI项目结论≥ 业务红线，且区分含税 / 不含税口径混算，GMV 与实收混用
无效占比浪费程度设定「待观察」档，不用二分法两档判定会把中间态算成无效

HOW TO USE这套 SOP 不要求一次跑完六步再动手。实际投放里 S4 和 S5 是循环的：测一轮 → 判一轮 → 重排一轮，每轮把结论写回 S1 的 Brief。跑过三轮之后，Brief 里的假设会越来越准，这才是 SOP 真正的复利。
BOUNDARY

适用边界

这套东西在什么条件下成立、什么条件下会失效，先说清楚。

01
适用：有明确转化目标的付费投放（信息流、达人种草、联盟 CPS），单周期预算 50 万以上、能拿到后端成交数据的场景。预算太小时，测试位分不出来，S2 的分层没有意义。
02
部分适用：品牌广告、纯曝光型投放。这类目标不能用 CPA / ROI 判定，S5 需要换成声量份额、搜索指数、品牌词增量等指标，其余结构可以保留。
03
不适用：没有归因链路、拿不到后端数据的场景。这种条件下只能做平台内的相对优化，无法判断项目是否赚钱——不要用过程指标硬凑结论。
04
阈值需要重标定：S1 的 CPA 上限、S4 的最小样本、S5 的基准区间都跟品类强相关。换品类必须用自己前三轮的数据重新标定，不能直接套用。
05
来源说明：这套流程来自实际投放复盘的方法沉淀，阈值区间参考了项目实测与公开基准区间，不含任何客户数据。它不是某个平台的官方方法论，是我自己跑过、改过的工作流。
